# cruella
 
## 📌 프로젝트 소개
Cruella는 [그룹웨어 시스템 서비스]를 제공하는 웹 프로젝트입니다.

## 🛠️ 사용 기술
- Front-end: HTML, CSS, JavaScript
- Back-end: Java, JSP, Servlet
- Database: Oracle DB
- 서버: Apache Tomcat 9

## ✨ 주요 기능
- 회원가입 / 로그인 / 로그아웃
- 게시판 / 게시판 CRUD
- 알림 / 채팅
- 전자서명

## 나의 역할
- 김동규 : 회원서비스
  
           ▫️ 로그인 / 비밀번호 발급 및 변경
           ▫️ 출퇴근
           ▫️ 근태 및 휴가관리
           ▫️ 메모, 전자서명 관리
